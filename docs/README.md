# Yaremche - Туристичний портал міста

## 📋 Коротко про проект

**Yaremche** - це комплексний інформаційний портал для туристів та гостей міста Яремче. Платформа об'єднує всю необхідну інформацію про заклади, визначні місця, туристичні маршрути та сервіси міста в одному зручному інтерфейсі.

## 🎯 Цільова аудиторія

### Поточна (MVP)
- **Туристи та гості міста** - відвідувачі, які планують або вже перебувають в Яремче
- **Адміністратори** - управління контентом через Filament Admin Panel

### Майбутня (Phase 2)
- **Власники бізнесу** - можливість самостійно додавати та керувати своїми закладами

## 🔀 Git Workflow

### Структура гілок

- `main` - головна гілка з стабільним кодом
- `feature/назва-фічі` - гілки для нових функцій

### Процес роботи

1. Створюємо нову гілку: `git checkout -b feature/назва-фічі`
2. Розробляємо фічу
3. **Запускаємо PHPStan**: `./vendor/bin/phpstan analyse` — виправляємо всі помилки
4. Комітимо зміни
5. Пушимо в remote: `git push -u origin feature/назва-фічі`
6. Створюємо Pull Request в `main`
7. Code review та затвердження
8. Merge в `main`
9. Повертаємось на `main` та пулимо: `git checkout main && git pull`
10. Приступаємо до наступної задачі

### Перевірки перед комітом

```bash
# PHPStan — статичний аналіз коду
./vendor/bin/phpstan analyse
```

**Приклади назв гілок:**
```bash
feature/places-catalog
feature/user-authentication
feature/filament-admin
```
