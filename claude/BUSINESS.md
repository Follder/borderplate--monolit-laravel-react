# Elite Ski Club — Бізнес-логіка

## Користувачі

### Ролі
- **Client** — клієнт, купує заняття
- **Admin** — обробляє замовлення
- **SuperAdmin** — повний доступ, платіжні налаштування, сезони

### Авторизація
- Email + пароль (поточна реалізація)
- OTP (планується)
- Тиха реєстрація при першому замовленні
- Авторизація потрібна для доступу до історії занять

---

## Продукт

### Заняття
- Разові заняття з інструктором
- Тривалість: 1-8 годин
- Час заняття не вказується при бронюванні (узгоджується з адміном)

---

## Учні

### Рівні катання
```
beginner    — Початківець
novice      — Новачок
intermediate — Умілий
pro         — Профі
```

### Вікові групи
```
children  (3-6 років)   — тільки індивідуальні заняття
juniors   (7-12 років)  — тільки з однолітками (7-12)
adults    (13+ років)   — можуть займатись разом
```

### Правила сумісності

**По рівню катання:**
- ✅ Сусідні рівні можуть займатись разом (beginner + novice, novice + intermediate, intermediate + pro)
- ❌ Через рівень не можна (beginner + intermediate, novice + pro, і т.д.)

**По віку:**
- ✅ children (3-6) — тільки індивідуально (1 учень)
- ✅ juniors (7-12) — тільки між собою
- ✅ adults (13+) — між собою
- ❌ juniors + adults — не можна
- ❌ children + будь-хто — не можна

**Валідація:**
- Якщо учні несумісні → попередження + чекбокс підтвердження
- Можливо: кнопка "розділити на 2 заняття" → повна ціна за кожне

## Сезони та тарифи

### Типи сезонів
```
low      — Низький сезон
high     — Високий сезон
holiday  — Святковий сезон
```

### Структура
- Сезон може мати кілька періодів (напр. низький: 1-15.12 + 1-30.03)
- Суперадмін налаштовує діапазони дат
- Ціна заняття визначається датою заняття (не датою покупки)

### Сутності
- `Season` — назва, тип сезону
- `SeasonPeriod` — season_id, date_from, date_to
- `Tariff` — season_id, hours, price

## Ціноутворення

### Формула
```
Ціна = Базова ціна (за годину × сезон) + Додаткові учні

Додатковий учень = +50% базової ціни (коефіцієнт з адмінки)
```

### Приклад
- 1 учень: 4000 грн
- 2 учні: 4000 + 2000 = 6000 грн
- 3 учні: 4000 + 2000 + 2000 = 8000 грн

---

## Замовлення

### Процес
1. Клієнт вибирає дату заняття
2. Вибирає кількість годин (1-8)
3. Додає учнів (вік + рівень катання)
4. Система перевіряє сумісність учнів
5. Показує фінальну ціну
6. Оплата через MonoPay (100% передоплата)
7. Email з підтвердженням
8. Адмін зв'язується для уточнення часу

### Статуси
```
pending    — Неоплачено
paid       — Оплачено
completed  — Виконано
cancelled  — Скасовано
refunded   — Повернено
```
